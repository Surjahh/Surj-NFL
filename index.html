The engine compares an adaptive ridge-regression model with a recency-weighted, shrinkage baseline. It uses walk-forward testing, tracks residual uncertainty, and falls back to the baseline when training history is insufficient. Model fit is not proof of predictive edge.

Automatic team defense by prop market

Pulls public nflverse team-game stats and estimates how much a defense allows relative to league average.

Not loaded
No key required. Public data is cached for up to six hours per warm server instance. Select the defense and market, then load the adjustment.

Adjustment compares opponent stats allowed per game with league average and caps the result at ±15%. Receiving yards use team passing yards allowed as a proxy. It is descriptive, not a proven predictive edge. Early-season samples can be noisy.
